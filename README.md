# Forests

自分のペースで森に暮らす、オリジナル3Dスローライフ。

**あなたは何もしなくて大丈夫です。** 開発・修正・検証はこちらで進めます。

## いま遊べるもの

リポジトリの `play/` に **ブラウザ版** があります（Godot HTML5）。  
iPhone でも Safari で開けます（ホーム画面追加でアプリ風に）。

Mac / Xcode / Godot のインストールは不要です。

## 開発の本線

| 項目 | 内容 |
|---|---|
| エンジン | Godot 4.3（`godot/`） |
| 目標 | App Store 品質（提出だけは最終的に Apple アカウントが必要） |
| いま | MVP：歩く・採る・かばん・セーブ |

詳細: `docs/TECH_DECISION.md` / `docs/MVP_PLAN.md` / `docs/IOS_EXPORT.md`

## 操作

- 左スティック（または WASD）で歩く
- 右スワイプ（または右ドラッグ）でカメラ
- タップで調べる →「採る」
- かばん / 設定 / 記録
