# Forests MVP — 画面・操作・構成・フェーズ

## ゲーム一文

**Forests** — 自分のペースで森に暮らし、採集し、世界が少しずつ豊かになるオリジナル3Dスローライフ。  
（既存作品のキャラ・名称・UI・音楽は使わない。）

## MVP必須（指示書 §4）

1. 3Dフィールド（草地・木・岩・花・水辺、歩行可能な小マップ、追従カメラ）
2. プレイヤー（オリジナル姿、移動・向き・待機/歩行、タッチ移動）
3. オブジェクト交流（タップで調べる・素材取得・インベントリ・取得フィードバック）
4. 基本UI（所持表示・インベントリ・設定・操作チュートリアル）
5. セーブ/ロード（位置・所持・採集状態・設定、再起動後復元）
6. パフォーマンス配慮（ローポリ、不要生成抑制）

## 画面構成（MVP）

```
[Game] 横画面 3Dワールド
  ├ HUD: 左下スティック / 右アクション / 上: 素材チップ
  ├ モーダル: インベントリ
  ├ モーダル: 設定（感度・BGM音量・データ削除）
  └ 初回: チュートリアルオーバーレイ（スキップ可）

[Boot] タイトル → 続きから / はじめから
```

## 操作（iPhone）

| 操作 | 内容 |
|---|---|
| 左下仮想スティック | 移動 |
| 右半分スワイプ | カメラヨー/ピッチ |
| ワールドタップ | 近くの対象を選択・調べる |
| 右アクションボタン | 選択中対象を採取 |
| 上の袋アイコン | インベントリ |
| 歯車 | 設定 |

## 主要コンポーネント

| 名前 | 責務 |
|---|---|
| `GameState` (Autoload) | 所持・設定・セッション |
| `SaveService` | `user://save.json` 読み書き |
| `PlayerController` | スティック移動・アニメ相当 |
| `CameraOrbit` | 追従 + スワイプ |
| `Interactable` | 木/花/岩の調査・採集 |
| `InventoryUI` | 一覧表示 |
| `VirtualJoystick` | タッチ移動入力 |
| `WorldBootstrap` | 小マップ生成・配置 |

## 実装順序（このPRで進める）

1. プロジェクト生成・Autoload・タイトル  
2. 3Dマップ + プレイヤー + カメラ  
3. 仮想スティック + スワイプカメラ  
4. Interactable + フィードバック  
5. インベントリ / 設定 / チュートリアル  
6. セーブ・ロード  
7. ヘッドレス検証 + iOSエクスポート手順書

## 最初に完成させる機能（今すぐ）

**「スティックで歩き、木をタップして素材を取り、インベントリに入り、セーブして再起動後も残る」**  
これが通れば MVP の核は達成。
